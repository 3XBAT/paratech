Cause (reviewer confirmed from the code): `desktop/frontend/src/pages/SubjectsPage.tsx` ~822/825, `TeachersBlock` and `SubjectTabs` are siblings with the same `key={subject.id}` (neighbour `CallLinkBlock` already uses a prefix). Fix: `key={`teachers:${subject.id}`}` plus a frontend test that switches subjects and expects one `section.teachers`; then drop the `.first()` in `06-send.spec.ts` (`sendDialog`/`removeTeachers`). Needs a bug task (out of scope here: no app code changed).

## Decisions to confirm
1. **AC conflict «смена срока … видна в «Журнал»».** By design the student's own add/edit/delete is not journaled (`input/wails/homeworkcreate.go:59`, `homeworkchange.go:64,131`, ADR-0029); the journal names only an agent's change («Изменён срок задания», agent pack TASK-380). The journal row pins the actual behaviour (no own-edit line; the journal itself is proven non-empty by a «Решение задания» line from the row's own draft). Owner: confirm, or ask for a journal of the student's own edits (product task).
2. **No extraction row.** No UI path runs the LLM extraction over an existing summary/text (only the recording import, covered by the recording pack TASK-378; material extraction is an agent tool). Nothing invented. «Date alone → 20:00» is covered at the add dialog.
3. **Delete confirmation.** A plain delete is immediate with «Вернуть»; the question «Работа остановится — удалить?» exists only while work (draft, writing, triage) is running and the scripted fake answers instantly, so it is not reached.
4. «Сохранить в файл» in the build is «Сохранить ▾» → «Файл .txt» (writes `homework.md` in the data dir, no dialog) and «Word (.docx)» (the save dialog → `<ctl>/saved`); both checked.
5. The date/time inputs show US formats (`mm/dd/yyyy`, `08:00 PM`) on this machine (cosmetic, locale of WebView2).
6. A filter `--grep "@settings|@assignments"` does not work through npm on Windows (only the first tag ran): use `-- --project settings --project assignments` (the tasks.json test step says `--grep @assignments`, which on a fresh sandbox gives «не проверено»).
