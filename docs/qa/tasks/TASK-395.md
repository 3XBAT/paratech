# TASK-395: тишина вместо общего лимита для ответа на вопрос

Студент ничего нового не увидит: изменение в клиенте Hub. Длинный ответ на вопрос («answer_question» агента и ответ на вопрос студента) больше не обрывается через 5 минут, а только если Hub молчит 60 секунд (до первого сообщения — 2 минуты) или всё длится больше 10 минут. Проверка владельца:

1. Hub нужно перезапустить из ветки TASK-394 или новее (иначе он не шлёт heartbeat); приложение запускать не нужно.
2. `go -C paratech test -race -count=1 ./desktop/internal/adapters/hubclient/...` — зелёный. Тесты `TestAnswerQuestionStreamWatchdog` и `TestStepStreamHeartbeat` проверяют: heartbeat удерживает молчащий поток, полная тишина обрывает с таймаутом, поток дольше прежнего лимита с сообщениями проходит, общий предел 10 минут (в тесте уменьшен) обрывает, без heartbeat (старый Hub) всё как раньше.
3. В живом приложении после запуска нового Hub: длинный вопрос по конспектам отвечает целиком, а при остановленном провайдере через ~60 с появляется обычное «Нет связи» без зависания.
