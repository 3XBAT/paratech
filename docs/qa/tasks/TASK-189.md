# TASK-189 — проверка владельцем

1. В панели помощника написать «сделай презентацию на тему X» без загруженного задания: появляется карточка «Такого задания нет — могу сделать как свободную работу (с уточняющими вопросами)» с кнопками «Сделать» и «Не надо» и галочкой «Больше не показывать».
2. Двойной клик по «Сделать»: запускается одна работа; кнопки на время вызова неактивны; затем карточка работы, помощник задаёт вопросы, в конце презентация.
3. Новый запрос, «Не надо»: строка «Не делаем».
4. Закрыть и снова открыть нить с выполненной работой: показана карточка работы, а не кнопки.
5. Поставить галочку «Больше не показывать» и ответить: следующий запрос по теме идёт без карточки.
6. «Настройки» -> «Помощник» -> «Предупреждать перед свободной работой»: включить, карточка снова появляется.
