# TASK-208 — проверка владельцем: кольцо контекста у поля ввода

1. Холодный запуск: пока нет ни одного чата, кольца нет. В пустом чате слева от кнопки отправки видно маленькое пустое серое кольцо (0 %). Если заполнение чата не удалось прочитать, кольца нет совсем, без «битого» значка.
2. Отправьте пару просьб: слева от кнопки отправки появляется маленькое серое кольцо, чуть закрашенное. Наведите курсор: «Контекст чата: N %. Столько разговора агент помнит сейчас.»
3. Пока просьба идёт, кольцо не меняется и не «бегает»; значение обновляется, когда ответ готов.
4. Переключитесь на другой чат и обратно: у каждого чата своё кольцо.
5. Цвета в обычной работе проверить трудно: 70 % значит около 14 ответов в окне из 20 (или 34 КиБ истории). Для проверки нужен длинный чат (14+ просьб с большими ответами; для 90 % — 18+). С 70 % кольцо становится акцентным (в подсказке: «Чат заполняется…»), с 90 % под полем появляется строка «Начать новый чат» с кнопкой «Новый чат». Кнопка открывает пустой чат, фокус в поле ввода, кольцо пустое.
6. После автоматического уплотнения контекста (TASK-269/270, позже) кольцо покажет меньшее значение.
7. Что покрыто только тестами (node, `agentcontextring.test.mjs`): все три уровня, переполнение как «полный», отсутствие кольца при неизвестном заполнении, кнопка «Новый чат» в строке, выбор значения между списком и обновлением, отсутствие анимации при `prefers-reduced-motion`.
8. Тёмная и светлая тема: кольцо видно в обеих, один акцент, без красного. Цвет не единственный признак: процент и пояснение всегда в подсказке.
