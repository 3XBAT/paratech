# TASK-208 — проверка владельцем: кольцо контекста у поля ввода

1. Холодный запуск: пока нет ни одного чата, кольца нет. В пустом чате кольца тоже нет (0 %): оно появляется после первых ответов. Если заполнение чата не удалось прочитать, кольца нет совсем, без «битого» значка.
2. Отправьте пару просьб: слева от кнопки отправки появляется маленькое серое кольцо, и после ответов оно немного закрашивается. Наведите курсор: «Контекст чата: N %. Агент помнит весь разговор.»
3. Отправьте просьбу, на которую агент покажет план, и подождите: пока идёт работа, пока план ждёт «Да» и после нажатия «Да», кольцо не меняется и не «бегает»; значение обновляется, когда просьба закончена (готово, остановлено или ошибка).
4. Переключитесь на другой чат и обратно: у каждого чата своё кольцо. После «Новый чат» кольца в пустом чате нет.
5. Цвета в обычной работе проверить трудно: 70 % значит около 14 ответов в окне из 20 (или 34 КиБ истории). Для проверки нужен длинный чат (14+ просьб с большими ответами; для 90 % — 18+). С 70 % кольцо становится акцентным (в подсказке: «Скоро агент начнёт сжимать начало разговора.»), с 90 % под полем появляется строка «Начать новый чат? Этот чат почти заполнен и останется в списке.» с кнопкой «Новый чат». Кнопка открывает пустой чат, фокус в поле ввода, кольца нет.
6. После автоматического уплотнения контекста (TASK-269/270, позже) кольцо покажет меньшее значение.
7. Что покрыто только тестами (node, `agentcontextring.test.mjs`): все три уровня, переполнение как «полный», отсутствие кольца при неизвестном заполнении и при 0 %, кнопка «Новый чат» в строке, выбор значения между списком и обновлением (в том числе пока план или вопросы ждут ответа), отсутствие анимации при `prefers-reduced-motion`.
8. Тёмная и светлая тема: кольцо видно в обеих, один акцент, без красного. Цвет не единственный признак: процент и пояснение всегда в подсказке.
