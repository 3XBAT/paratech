# TASK-356 — меню «Настроек» (проверка владельца)

Начните с холодного запуска (чистые настройки, без ключа и адреса). Откройте «Настройки» в панели слева.

1. **Меню.** Сверху «Основные, Подключения, Профиль, Оформление», ниже тонкая линия с мелкой подписью «Дополнительно» и «Модели речи, Диагностика». Надстрочника «Изменения сохраняются сразу» над заголовком нет. На узком окне группа переносится отдельной строкой.
2. **«Подключения» → карточка «Конспекты и задания».** Адрес и ключ не заданы: сверху подсказка «Нужны ключ доступа и адрес сервера — их выдаёт автор приложения…», под ней «Ключ доступа», ниже раскрытый блок «Адрес сервера» (со стрелкой). Подсказка стоит прямо над полем ключа.
3. **Адрес сохранён и сервер отвечает.** Блок «Адрес сервера» свёрнут (стрелка вправо, текст читается как кнопка); Enter/Space его раскрывают, рамка фокуса видна. Раскрытый вручную блок не сворачивается, пока вы печатаете или после сохранения.
4. **Ошибка.** Неверный адрес, «Сохранить адрес»: блок остаётся открытым, под полем причина по-русски. То же при «Нет связи» с сервером.
5. **Хлебные крошки.** На «Подключения» (карточка → «Назад»), «Apple Календарь», «Модели речи», «Диагностика» над заголовком путь вида «Настройки › …» вместо надстрочника; клик по «Настройки» возвращает.
6. Место для «Разрешений» после «Основных» оставлено, пункта пока нет (TASK-361).
