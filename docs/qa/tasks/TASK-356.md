# TASK-356 — меню «Настроек» (проверка владельца)

Начните с холодного запуска (чистые настройки, без ключа и адреса). Откройте «Настройки» в панели слева.

1. **Меню.** Сверху «Основные, Подключения, Профиль, Оформление», ниже тонкая линия с мелкой подписью «Дополнительно» и «Модели речи, Диагностика». Надстрочника «Изменения сохраняются сразу» над заголовком нет. На узком окне группа переносится отдельной строкой.
2. **«Подключения» → карточка «Конспекты и задания».** Адрес и ключ не заданы: под общей строкой про ключ и звук подсказка «Нужны ключ доступа и адрес сервера — их выдаёт автор приложения…», прямо над полем «Ключ доступа». Ниже блок «Адрес сервера» со стрелкой уже раскрыт.
3. **Адрес сохранён и сервер отвечает.** Блок свёрнут, в строке виден адрес («Адрес сервера · …»). Enter/Space его раскрывают, рамка фокуса видна. Пустой адрес → впишите → «Сохранить адрес»: блок остаётся раскрытым, виден «Сохранено.». Раскрытый вручную блок не сворачивается, пока вы печатаете.
4. **Ошибка.** Неверный адрес, «Сохранить адрес»: блок открыт, под полем причина по-русски. То же при «Нет связи» с сервером.
5. **Путь над заголовком.** В «Подключениях» откройте любую карточку и «Календарь на iPhone, iPad и Mac»: над заголовком путь «Подключения / <раздел>», кнопки «Назад» нет. Клик по «Подключения» возвращает к карточкам, фокус на открытой карточке. Внизу справки Apple кнопка «Вернуться к подключениям». Tab с открытого раздела идёт сразу к полям, к пути — Shift+Tab (как на других экранах с путём). На «Модели речи», «Диагностика», «Оформление» надстрочника над заголовком нет.
6. Место для «Разрешений» после «Основных» оставлено, пункта пока нет (TASK-361).
