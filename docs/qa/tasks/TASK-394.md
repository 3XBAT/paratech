# TASK-394: heartbeat Hub в потоковых вызовах

Это контракт и серверная часть Hub: студент ничего не увидит. Приложение начнёт использовать heartbeat в TASK-395. Проверка владельца:

1. Остановите запущенный Hub и запустите заново из этой ветки (старый процесс не знает нового поля). Приложение запускать не нужно.
2. В `paratech` выполните `go -C paratech test -race -count=1 ./hub/internal/input/connect/...` — зелёный; тесты `TestStream...Heartbeat...` проверяют: молчание провайдера 2,5 интервала даёт 2 heartbeat, затем дельты и результат; ошибка провайдера после heartbeat — ошибка без результата; без флага heartbeat нет; повтор с тем же ключом с флагом и без — бесплатный, без конфликта.
3. В `paratech/shared`: `buf lint` и `buf breaking --against "<корень репозитория>#format=git,ref=origin/master,subdir=paratech/shared"` без ошибок.
4. Работа приложения не меняется: старое приложение (без флага) получает те же потоки, что и раньше.
