# TASK-352 — все входы ведут на экран пары (проверка владельца)

Начните с холодного запуска приложения. Нужны: пара с записью и готовым конспектом, пара, которая идёт сегодня позже без записи, запись с заданием, найденным в ней, и, лучше, пара только с вашими файлами («Мой конспект» без записи). Первым делом вы видите «Сегодня»: строки пар дня, под ними «Нужно ваше решение», «Сроки на неделе» и «Итоги дня».

1. «Сегодня»: наведите курсор на строку пары с записью — вся строка подсвечивается. Нажмите в любом месте строки (и Tab → Enter): открывается экран пары, путь «Предметы / <предмет> / <пара>». Отдельной кнопки «Открыть» в строке нет. Рамка фокуса при Tab обводит всю строку.
2. «Сегодня»: пара, которая ещё не началась или идёт и не имеет записи, показывает кнопку «Записать» вместо открытия; она открывает «Записи» с панелью запуска. Закончившаяся пара без записи — обычная строка без кнопок. Пока записывается, строка пары ничего не открывает (видна метка «Идёт запись»).
3. «Сегодня»: пара с готовым конспектом встречается один раз — её строкой. В «Итогах дня» её нет (остаются только итоги других пар и сообщение с вопросом про календарь, но без кнопки «Открыть»).
4. «Записи»: у строки готовой записи одна кнопка «Открыть» (вся строка — её цель; клик по галочке выбора, по «⋯», «Повторить» и меткам статуса пару не открывает). Она открывает пару на «Конспект», пока он готов; если конспекта ещё нет, а «Текст лекции» готов — на «Текст лекции»; иначе на «Расшифровку». В «⋯» остальные вкладки: «Открыть текст лекции», «Открыть расшифровку» — открывают ту же пару на своей вкладке.
5. «Предметы» → предмет → блок «Пары»: строки пар кликабельны целиком (подсветка, фокус), открывают пару; метки «Конспект готов», «новое» на месте.
6. «Задания» → задание, найденное в записи: под ним одна кнопка «Открыть пару» (при нескольких записях — «Открыть пару · 14:05»). Она открывает пару на тексте лекции, конспекте или расшифровке — по тому, что готово.
7. Агент: в панели упомяните пару через @ («Пара: …»), отправьте, нажмите метку пары в сообщении — открывается экран этой пары (на пару без записи и файлов приходит строка «У этой пары нет записи и конспекта: открывать нечего.»). Источник ответа агента (расшифровка, текст лекции, конспект) открывает пару сразу на нужной вкладке и показывает найденное место; источник из ваших файлов — на «Мой конспект».
8. Холодный старт в пару только с вашими файлами: откройте её, затем закройте приложение и запустите заново; Alt+← / Alt+→ после перехода по истории показывают её без ошибки «только из списка пар» — пара загружается по ключу. Если пара уже удалена, видно сообщение по-русски и кнопка «Назад».
9. Удаление записи на экране пары: «⋯» в шапке → «Удалить запись» → подтвердите. Вы попадаете туда, откуда пришли (в «Записи», в предмет, в «Сегодня», в задание), а не всегда в «Сегодня»; страница под парой перечитана, удалённой записи в ней нет. Если удалить нельзя, под шапкой красная строка с причиной, вы остаётесь на паре.
10. Старых экранов «Конспект» и «Расшифровка» с кнопкой «Назад» больше нет: везде одна пара с вкладками «Мой конспект · Конспект · Текст лекции · Расшифровка · Задания». Alt+← возвращает на страницу, откуда вы пришли.
11. Известное: у «Итогов дня» кнопка «Открыть» остаётся в строках, которых нет среди пар дня (вся строка там не кликабельна: внутри кнопки календаря); пара без записи и без файлов из «Сегодня» ничего не открывает.
