# TASK-352 — все входы ведут на экран пары (проверка владельца)

Начните с запуска приложения. Нужны: пара с записью и готовым конспектом, пара, которая начнётся сегодня позже без записи (и ещё одна, до которой больше десяти минут), запись с заданием, найденным в ней, и, лучше, пара только с вашими файлами («Мой конспект» без записи). Первым делом вы видите «Сегодня»: строки пар дня, под ними «Нужно ваше решение», «Сроки на неделе» и «Итоги дня».

1. «Сегодня»: наведите курсор на строку пары с записью — вся строка подсвечивается. Нажмите в любом месте строки, в том числе по метке «Конспект готов» (и Tab → Enter): открывается экран пары, путь «Предметы / <предмет> / <пара>». Отдельной кнопки «Открыть» в строке нет. Рамка фокуса при Tab обводит всю строку. Метка «Проблема с записью» остаётся отдельной кнопкой и ведёт в «Записи», а не в пару.
2. «Сегодня»: кнопка «Записать» есть у пары без записи только с десятой минуты до её начала и пока она идёт; пара, до которой больше десяти минут, и закончившаяся пара без записи — обычные строки без кнопок. «Записать» открывает «Записи» с панелью запуска (панель общая, на пару не настроена: запись привяжется к паре, которая идёт). Пока записывается, строка пары ничего не открывает (видна метка «Идёт запись»).
3. «Сегодня»: пара с готовым конспектом встречается один раз — её строкой. В «Итогах дня» её нет, даже если у неё нет сообщения от paratech, а строка открывает самую новую запись (остаются только итоги других пар и сообщение с вопросом про календарь, но без кнопки «Открыть»).
4. «Записи»: у строки готовой записи одна кнопка «Открыть» (вся строка — её цель; клик по галочке выбора, по кнопкам и по «⋯» пару не открывает, клик по метке статуса — открывает). Она открывает пару на вкладке по умолчанию, как «Сегодня» и «Предметы»: «Мой конспект», если в ней есть ваши файлы, иначе «Конспект», пока он готов, иначе первая вкладка с содержимым. В «⋯» названные вкладки: «Открыть текст лекции», «Открыть конспект», «Открыть расшифровку» — открывают ту же пару именно на своей вкладке.
5. «Предметы» → предмет → блок «Пары»: строки пар кликабельны целиком (подсветка, фокус), открывают пару; метки «Конспект готов», «новое» на месте.
6. «Задания» → задание, найденное в записи: под ним одна кнопка «Открыть пару» (при нескольких записях — «Открыть пару · 14:05»). Она открывает пару на вкладке по умолчанию, как остальные входы (не на «Расшифровке» или «Тексте лекции» по выбору кнопки).
7. Агент: в панели упомяните пару через @ («Пара: …»), отправьте, нажмите метку пары в сообщении — открывается экран этой пары (на пару без записи и файлов приходит строка «У этой пары нет записи и конспекта: открывать нечего.»). Источник ответа агента (расшифровка, текст лекции, конспект) открывает пару сразу на нужной вкладке и показывает найденное место; источник из ваших файлов — на «Мой конспект».
8. Без списка между ними и после смены раздела: откройте пару по ссылке из «Записи» или «Сегодня» — она загружается сразу по ключу, без захода в «Базу знаний». Пару только с вашими файлами откройте, перейдите в другой раздел и вернитесь Alt+←: она открывается без ошибки. (История и память окна живут до закрытия приложения; после перезапуска окно снова начинается с «Сегодня».) Если пару не удаётся показать, виден один из двух текстов: «Этой пары больше нет: запись или файлы удалены.» с кнопкой «Назад», или «Не удалось открыть пару.» с кнопками «Повторить» и «Назад».
9. Удаление записи на экране пары: «⋯» в шапке → «Удалить запись» → подтвердите. Вы попадаете туда, откуда пришли (в «Записи», в предмет, в «Сегодня», в задание), а не всегда в «Сегодня»; страница под парой перечитана, удалённой записи в ней нет; фокус клавиатуры уходит на окно, а не пропадает. Затем нажмите Alt+←: вы не возвращаетесь на удалённую пару, а уходите на раздел перед страницей, откуда пришли. Если удалить нельзя, под шапкой красная строка с причиной, вы остаётесь на паре.
10. Старых экранов «Конспект» и «Расшифровка» с кнопкой «Назад» больше нет: везде одна пара с вкладками «Мой конспект · Конспект · Текст лекции · Расшифровка · Задания». «Назад» и Alt+← возвращают на страницу, откуда вы пришли.
11. Известное: у «Итогов дня» кнопка «Открыть» остаётся в строках, которых нет среди пар дня (вся строка там не кликабельна: внутри кнопки календаря); пара без записи и без файлов из «Сегодня» ничего не открывает, а агентская метка «Пара» пока заходит через «Базу знаний».
