# TASK-253 — как проверить

1. Откройте страницу лекции, вкладка «Конспект», блок «Мой конспект».
2. Добавьте DOCX с несколькими заголовками 1-3 уровня: у части должно быть «N разделов».
3. Добавьте Markdown-файл с двумя и более заголовками: «N разделов».
4. Добавьте обычный TXT без заголовков: «1 фрагмент».
5. Добавьте фото страницы: счётчика у части нет (страницы фото считаются отдельно: «N стр. без текста»).
6. Удалите или повредите файл: список открывается, у такой части счётчика нет.
7. PDF: «N стр.» появится после TASK-156.
