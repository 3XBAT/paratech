# TASK-350 — хлебные крошки (проверка владельца)

Начните с холодного запуска приложения: откроется «Сегодня». Крошек там нет — они только на вложенных экранах.

1. **Задания.** Откройте «Задания» и любое задание. Над заголовком слева строка «Задания / Название задания»: «Задания» — ссылка (акцентный цвет), название серое. Кнопки «Все задания» вверху нет. Клик по «Задания» возвращает к списку; Alt+← после этого идёт по истории. Длинное название обрезается многоточием, подсказка при наведении показывает полное.
2. **Билеты.** «Предметы» → «Билеты» (или как открывается у вас): «Предметы / Билеты». Без предметов: заголовок «Билеты», ниже «Сначала нужен предмет», кнопка «Перейти к предметам»; повторного «Билеты» и надстрочника «Экзамен» нет.
3. **База знаний.** Предмет: «База знаний / Предмет»; пара из предмета: «База знаний / Предмет / Пара». Каждая ссылка возвращает на свой уровень (в поиске результаты на месте).
4. **Конспект и расшифровка.** Откройте конспект с «Сегодня»: первая крошка «Сегодня / Конспект», клик возвращает на «Сегодня». Из «Заданий» — «Задания / …». Расшифровка — так же.
5. **Предметы.** Над названием предмета нет надстрочника «Библиотека»; семестр и «Также: …» — одной серой строкой под названием.
6. **Клавиатура.** Tab доходит до каждой крошки-ссылки, виден контур фокуса, Enter/Пробел переходит на уровень выше. Контур слева не обрезан.
7. Ошибка загрузки задания или удалённое задание: крошка «Задания» остаётся сверху — выход есть.
