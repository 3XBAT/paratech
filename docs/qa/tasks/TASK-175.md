# TASK-175 — проверка владельцем

1. «Сегодня» с открытой панелью: окно 1100–1600 px, панель 320–480 px — одна колонка на узком, две без сжатия левой на широком; кнопки под «Спросить paratech» ровные.
2. Отправьте просьбу: поле ввода уходит вниз, фокус и черновик сохраняются.
3. В поле: Enter отправляет, Shift+Enter — новая строка, поле растёт до 6 строк, потом скролл; при русском IME Enter выбор не отправляет.
4. Ctrl+K на русской раскладке открывает панель и фокусирует поле; повторный Ctrl+K закрывает панель.
5. «Оформление»: галочка ровно по центру выбранного цвета.
6. Карточка ожидания: точки по центру.
7. Регрессия: ресайз панели и двойной клик (TASK-143), Стоп / «Отправить ещё раз» (TASK-137).
