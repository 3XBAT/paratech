# TASK-339 — «Входящие»: проверка владельцем

Запуск с нуля: открыть приложение, раздел «Предметы». Первым студент видит блок «Входящие» (если там есть файлы) над карточками предметов; у каждого файла кнопка «Разложить» и «⋯».

## 1. Файл во «Входящих»
1. «Добавить файл» на странице «Предметы» (подсказка «Файл попадёт во «Входящие»»): строка файла с «Разложить», «⋯» и (если нашлось совпадение) строкой «Похоже на: Сети → Лабораторные · Положить» — для файла с названием предмета и «ЛР»/«лаб»/«сем»/«лек» в имени. Без совпадения строки подсказки нет.
2. «Положить» в подсказке: файл уходит из «Входящих», внизу «Положено в «Сети → Лабораторные». Вернуть»; «Вернуть» возвращает его во «Входящие».
3. Если предмета нет, но он есть в расписании: «Есть в расписании: «Сети» · Создать предмет «Сети» и положить». После клика «Создан предмет «Сети», файл положен в «Материалы». Вернуть»: «Вернуть» убирает файл и пустой предмет.
4. «Разложить»: панель «Предмет / Папка»; предмет не выбран заранее, «Положить» недоступна, пока он не выбран; «Новый предмет…» открывает ввод имени, Esc возвращает к выбору, второй Esc закрывает панель.
5. «⋯» (и правая кнопка): Открыть (файл открывается в Word/PowerPoint), Разложить…, Удалить. «Удалить» — без вопроса, строка «Удалено «имя». Вернуть» на ~10 с; «Вернуть» возвращает файл на место.
6. Перетащить значок файла на карточку предмета: карточка подсвечивается подписью «Положить в «Сети → Материалы»», после отпускания файл в «Материалы» и строка «Вернуть». Перетаскивание файла из Проводника в окно по-прежнему кладёт его во «Входящие».

## 2. Страница предмета
1. Слева в дереве семестр — маленький заголовок капсом, а не папка; папки в дереве кликаются и прокручивают к своему разделу.
2. «Добавить файл» рядом с «Все предметы» (подсказка «Файл попадёт в «Материалы»») и «+» у каждой папки: файл лежит сразу в предмете/папке; результат виден под заголовком папки.
3. Тот же файл уже лежит в другом предмете: «Этот файл уже есть: «Физика → Лекции».» и кнопки «Переместить сюда», «Открыть предмет».
4. Строки файлов в папках: «Открыть» и «⋯» (Переместить…, Вернуть во «Входящие», Удалить с «Вернуть»).
5. Отказ (папка удалена, файл слишком большой): красная строка с причиной и «Повторить» или «Обновить список».
