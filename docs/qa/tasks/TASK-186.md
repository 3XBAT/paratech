# TASK-186 — проверка владельцем

1. Открыть страницу задания. Блок называется «Быстрый черновик»; кнопки «Новый черновик»/«Доработать черновик»; статус «Черновик не готов/готов». Версии, Word, отправка работают как раньше.
2. Ниже есть блок «Сделать под ключ» с подписью «Разбор задания и вопросы, затем работа или презентация файлом».
3. Нажать «Сделать под ключ»: кнопка неактивна на время вызова, затем появляется та же карточка работы, что в панели (вопросы, «Как я понял задание», план, разделы). Двойной клик — один разбор.
4. Закрыть и снова открыть страницу: карточка работы на месте, кнопки нет.
5. Проверить вид карточки на странице (отступы, ширина) и удобство расположения блока.
6. Без связи/без источника задания: текст ошибки на русском, кнопка остаётся.
