# TASK-337 — check steps

Start from a cold app: open the main window and the agent panel (the first screen is the usual panel with the input).

1. Open «Задания». Every row with a deadline reads «до ДД.ММ.ГГГГ, ЧЧ:ММ» with no seconds. Open an assignment: the page shows the same format. Check the «Сегодня» screen and the summary page too.
2. In the agent panel ask for a list of assignments: the rows show the deadline without seconds.
3. Ask the agent any question. While it thinks, a small row of dots with a compact «Стоп» appears where the answer will be; there is no full-width banner. «Стоп» stops the request.
4. When the answer arrives it is plain text with no «Ответ» heading above it.
5. Windows setting «Анимации» off (reduced motion): the dots do not animate.
6. Look at both themes: the dots row and the reply card without a heading look quiet and aligned with the other messages.
