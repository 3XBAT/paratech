# TASK-353 — страница предмета с вкладками «Пары · Файлы · Задания» (проверка владельца)

Начните с запуска приложения. Нужен предмет с парами (запись и конспект), с файлами в папках и с одним-двумя открытыми заданиями (одно с прошедшим сроком, одно без срока — если получится), плюс пустой предмет. Первым делом вы видите «Сегодня»; откройте «Предметы» на панели слева: слева дерево («Входящие», семестры, предметы), справа последний открытый предмет.

1. Шапка предмета: название, строка с семестром, преподаватели, кнопка «Билеты к экзамену» и «⋯» (подсказка «Ещё действия с предметом»). Кнопок «База знаний», «Билеты», «Добавить файл» и «Удалить предмет» в шапке нет. «Удалить предмет» — в «⋯»; диалог как раньше, после «Отмена» фокус возвращается на «⋯». Под шапкой три вкладки.
2. Вкладка по умолчанию: «Пары», если у предмета есть пары, иначе «Файлы». При открытии предмета ничего не мигает: сначала пустое место, «Загрузка…» появляется, только если чтение идёт дольше ~1 секунды. Выберите другую вкладку, откройте другой предмет и вернитесь — вкладка выбирается заново; выбранную вами вкладку программа не переключает сама.
3. «Пары»: строки пар предмета по датам; строка целиком открывает экран пары. У пары в обработке видна метка «В обработке», у неудавшейся — «Сбой обработки», у свежего конспекта — «новое». Кнопки «Импортировать запись» и «Добавить конспект прошедшей пары» (открыта только одна форма за раз; пока идёт импорт, вторая кнопка выключена с причиной). В «⋯» вкладки («Ещё действия с парами») — «Сохранить все конспекты одним файлом» (если нечего сохранять — пункт выключен с причиной «Нельзя сохранить…»). У предмета без пар: «Записей по предмету пока нет.» и те же две кнопки.
4. Откройте пару и вернитесь («Назад» или Alt+←): вы на той же вкладке «Пары», без мигания «Загрузка…».
5. «Файлы»: сверху «Добавить файл» (файл попадает в «Материалы»), ниже папки как раньше, пустые — строкой «Пусто: … [+]». Нажмите «+» у пустой папки и добавьте файл: папка становится разделом, фокус остаётся на её «+». Нажмите папку в дереве, когда открыта другая вкладка: откроются «Файлы» и страница прокрутится к папке. «Папка» под деревом при другой вкладке тоже открывает «Файлы».
6. «Задания»: открытые задания предмета по сроку (просроченные первыми, без срока — внизу), у каждого метка срока или «Просрочено»; строка целиком открывает задание. «Добавить задание» открывает форму с уже выбранным предметом; после добавления новая строка получает фокус. Если список не удалось обновить, над ним строка «Список не обновился…» и «Повторить». Пусто: «Открытых заданий по предмету нет…» и кнопка.
7. «Билеты к экзамену»: открываются «Билеты» с этим предметом; путь «Предметы / <предмет> / Билеты к экзамену»; список предметов скрыт, видно «Предмет: <название> Сменить». Нажатие на название предмета в пути возвращает на страницу предмета; Alt+← — на ту же вкладку.
8. Вкладки переключаются стрелками, Alt+← не считает переключение вкладки отдельным шагом. «База знаний» (поиск по всем парам) пока доступна кнопкой под деревом, рядом с «Предмет» и «Папка».
9. Известное: счётчик «Задания · N» может появиться позже счётчика «Пары»; для пар старше десяти последних метки статуса не показываются.
