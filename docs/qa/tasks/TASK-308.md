# TASK-308 — окончательное стирание удалённого предмета через 3 дня: проверка владельцем

Это ядро без своего экрана. Запуск с нуля: открыть приложение, раздел «Предметы»; первым виден список предметов слева.

Подготовка: предмет «Тест» с конспектом, файлом и преподавателем; рядом задание и запись пары с этим названием. Удалить предмет («Удалить предмет», TASK-289).

## 1. Окно в 3 дня
1. Сразу после удаления: предмета нет в списке, «Добавить предмет» с тем же именем отвечает «Предмет с таким названием удалён» и предлагает «Вернуть».
2. Сдвинуть системные часы на 3 дня вперёд (или подождать) и перезапустить приложение: предмета нет, а «Добавить предмет» с тем же именем создаёт новый чистый предмет без старых конспектов и файлов («удалён» не появляется).
3. Без перезапуска, если приложение работало всё это время: добавление предмета с тем же именем через 3 дня тоже проходит (стирание запускается само при проверке имени).
4. «Вернуть» через 3 дня уже не работает: «Предмет удалён окончательно».

## 2. Что остаётся
- Задание и запись пары остаются; в них предмет показывается обычной строкой-названием.
- Файл, из которого сделана работа (курсовая/реферат), и файл из конспекта другого предмета не стираются, а оказываются во «Входящих».

## Что важно знать
- Ежедневный проход идёт раз в сутки и при старте; списка «Недавно удалённые» пока нет (ядро готово, нужна отдельная задача на экран).
- Ручная проверка на живом приложении по смыслу совпадает с автотестами: `desktop/tests/subject_purge_sqlite_test.go`.
