# TASK-381: проверка пакета «Задания»

Это тест, не функция приложения: студент ничего не увидит. Проверка владельца или супервайзера:

1. Запустите Docker Desktop и дождитесь, пока он будет готов.
2. Закройте свои прогоны E2E (одновременно идёт только один). Своё приложение можно не закрывать: прогон использует свой экземпляр.
3. Выполните (из корня репозитория):
   `bash C:/Users/xvati/GolandProjects/paratech-ops/heavy.sh npm --prefix C:/Users/xvati/GolandProjects/paratech/paratech/e2e run e2e -- --no-build --project settings --project assignments`
   (первый запуск без `--no-build`: соберёт E2E-приложение). Фильтр `--grep "@settings|@assignments"` через npm на Windows не работает.
4. На экране появится окно с пометкой « · E2E»: приложение само добавляет задания по предмету «История», меняет срок, отмечает «Выполнено», удаляет и возвращает, пишет черновик, открывает окно «Отправить задание?» и отменяет его. Звука нет, письма не уходят. Окно закроется само.
5. Откройте `paratech/dist/e2e-run/report/report.md`: строки «Задание: …» и «Журнал: …» должны быть «готово». Одна строка («Задание: отправка без почты преподавателя говорит причину») сейчас «сломано» — это найденная ошибка приложения (блок «Преподаватели» на странице предмета показывается несколько раз), снимок лежит в `report/screenshots`.
6. Проверьте, что ничего не осталось: в диспетчере задач нет `paratech.exe`, `hub.exe` из папки `paratech/dist`.

Решения владельца: см. progress/TASK-381.md (правки студента не пишутся в «Журнал»; нет пути извлечения заданий из готового конспекта).
