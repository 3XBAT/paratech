# TASK-341 — «Предметы» opens the tree and a subject (check steps)

1. Start the app cold with some subjects, click «Предметы» in the left rail. You immediately see the tree on the left («Входящие» first, then the semesters with subjects) and a subject on the right (the first one, no tiles).
2. Open another subject, go to another tab and come back: the same subject opens.
3. «Входящие» with files shows a bold name and a pill with the number; with none it is grey and has no number. Click it: the list of unsorted files with «Разложить», move, delete and «Вернуть».
4. Drag a file from «Входящие» onto a subject in the tree: the hint line above the tree tells where it goes, the subject is outlined, the file lands in «Материалы». While you scroll a long list, the tree stays in view.
5. In a subject press «Добавить файл»: the file goes into that subject. «База знаний» and «Билеты» are in the head, «Предмет» and «Папка» under the tree.
6. Alt+← goes back to the previous place; delete the open subject and go back/forward: no stuck entries.
7. Library without subjects: the tile screen with «Завести предметы из расписания» and «Добавить предмет» only. Create subjects from the schedule: the review panel keeps its result line and «Отменить» after the tree appears.
8. Switch off the Hub/disk read if possible: a failed list shows a line with «Повторить», never «пусто».
9. Check on screen: the pill/bold look in both themes, the sticky tree in a small window, no jump when you open «Входящие».
