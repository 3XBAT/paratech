# TASK-403: проверка владельцем

Нужен набор билетов, который не помещается в один документ (TASK-402). Реальный способ: в предмете список из нескольких сотен длинных билетов, подтвердить прогон, дождаться готовности. Если это непрактично, разбиение на части покрыто автотестами (`tickets.test.mjs`); на экране проверяется только старый набор с одним файлом (шаг 6).

1. Запустить приложение, открыть предмет, нажать «Билеты к экзамену». Первым виден список наборов предмета; готовый набор разбитого списка показывает статус «Ответы готовы».
2. В карточке готового набора сразу, без раскрытия, виден список частей по порядку: «Билеты 1–50», «Билеты 51–100» и так далее. Рядом с каждой частью маленькая иконка «Открыть»; при наведении подсказка «Открыть «Билеты 1–50»». Над списком: «Файлы лежат в папке «Билеты» предмета …» и «Файл разделён на части: не помещается в один документ.».
3. Нажать иконку одной части: на ней крутится индикатор, остальные иконки и «Вернуть» на это время неактивны; затем под этой частью строка «Открыта копия файла…», Word открывает копию. Нажать другую часть: у неё своя строка, первая остаётся.
4. Если файл части удалён или перемещён: под этой частью красная строка с причиной по-русски, иконка снова активна, остальные части открываются.
5. Иконка «Вернуть файлы во «Входящие»» (подсказка во множественном числе) переносит все части сразу.
6. Старый набор или короткий список (один файл): карточка как раньше, кнопка «Открыть .docx», без списка частей и без пояснения про разбиение, подсказка «Вернуть файл во «Входящие»».
