# TASK-247 — проверка владельцем

Холодный запуск приложения. Справа панель агента; в пустом чате под полем видно: «Через @ — указать предмет, пару, материал или задание», в поле справа внизу кнопка «@».

1. `npm --prefix paratech/desktop/frontend run test` и `run build` — зелёные.
2. Написать «@»: над полем (или под ним, если поле вверху) появляется короткий список последних предметов, пар, материалов и заданий; у каждого вид и пометка (предмет · дата). Набрать «мат» — список сужается без мигания.
3. Стрелки вверх/вниз двигают выбор, Enter или Tab выбирают, Esc закрывает список (текст и панель остаются). Выбранное — пилюля над полем с крестиком «Убрать «…»»; «@мат» из текста исчезает.
4. Набрать «@» и несуществующее название — «По «…» ничего не найдено»; Enter закрывает список, второй Enter отправляет.
5. Выбрать «@Матан», потом «@Физика», написать «сравни темы» и отправить. Пилюли очищаются, под просьбой в чате те же пилюли; агент отвечает по обоим предметам.
6. Backspace в пустом поле убирает последнюю пилюлю; на 8-й — подсказка «Можно указать не больше 8…».
7. Переименовать предмет и открыть чат заново: пилюля со старым названием, без пометки «удалено». Клик по пилюле предмета открывает «Предметы» с ним; пилюли пары и материала открывают «Базу знаний» и «Предметы» (подсказка при наведении говорит об этом). Удалить задание и нажать пилюлю: обычное состояние «не найдено» страницы.
8. После первого сообщения кнопка «@» остаётся: клик вставляет «@» и открывает список.
9. Поле выключено (нет подключения): список не открывается.
