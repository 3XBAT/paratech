# TASK-369 — агент видит названия записей и пар (проверка владельца)

Сначала переразверните Hub (промпт панели v9). Нужна хотя бы одна запись, у которой в «Предметах» нет предмета с её названием (например, предмет по расписанию «Социология культуры», которого нет в библиотеке).

## Проверка
1. С нуля: откройте панель агента, напишите «добавь предмет по последней записи». Агент не переспрашивает название: он сам смотрит записи и предлагает создать предмет с названием предмета последней записи (карточка подтверждения по обычной политике). После «Да» предмет появляется в «Предметах».
2. Спросите «у тебя нет возможности посмотреть название прошлой записи?» — агент не говорит «нет возможности»: называет название и предмет последней записи.
3. Спросите «какие у меня были записи на этой неделе»: в ответе названия записей и, где есть, преподаватель.
4. Если предмет с таким названием уже есть в «Предметах», агент говорит об этом и не создаёт дубль.
5. Если у последней записи нет ни предмета, ни названия предмета, агент задаёт один короткий вопрос — только в этом случае.
6. Известное: «добавить предмет» только создаёт предмет, запись к нему не привязывается (это отдельное действие).
