# TASK-120: панель агента (проверка владельцем)

1. Запустить приложение: справа на каждом экране панель агента; в её заголовке поле ввода.
2. Нажать Ctrl+K на любом экране: фокус уходит в поле панели.
3. Ярлык контекста показывает текущий раздел; крестик меняет его на «Без предмета»; при смене раздела ярлык возвращается.
4. Без ключа Хаба: поле неактивно, «Нет связи с paratech». После настройки Хаба и возврата на страницу поле снова активно.
5. Кнопка «Отменить» в строке действия неактивна (до TASK-123); истории нет (до TASK-123).
6. Карточки плана, вопросов и результата проверяются на живом Хабе после TASK-123; пока их покрывают тесты.
