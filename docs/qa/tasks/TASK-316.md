# TASK-316 — «Выполнено»: проверка владельцем

Запуск с нуля: открыть приложение, раздел «Задания». Первым студент видит список открытых заданий: слева у каждой строки круглая отметка, справа «Открыть» и «⋯».

## 1. Список
1. Навести на круг: подсказка «Отметить выполненным». Нажать (или Tab до круга и Enter/Пробел): строка уходит из «Открытых», внизу (над границей окна, не поверх панели агента) тёмная плашка «Выполнено: «название» · Отменить», фокус на круге соседней строки.
2. «Отменить» (или Ctrl+Z вне поля ввода): строка вернулась. Плашка сама исчезает через ~10 с, но не пока на ней мышь или фокус и не пока окно свёрнуто.
3. Переключатель «Открытые / Выполненные / Все»: в «Выполненных» строка приглушена, название зачёркнуто в «Все», в мете «Выполнено 28 окт.», круг закрашен, подсказка «Вернуть в работу». Пустые «Выполненные»: «Пока ничего не отмечено…» и кнопка «Показать открытые». Фильтр по письмам при «Выполненных» скрыт; при смене переключателя он сбрасывается.
4. «⋯» → «Удалить»: как раньше (красной кнопки в строке больше нет); у задания с идущей работой — предупреждение и «Отмена», фокус возвращается на «⋯».

## 2. Страница задания
1. Кнопка «Отметить выполненным» (не акцентная) рядом с «Изменить» и «Удалить». После нажатия: строка «Выполнено 28 окт.», кнопка «Вернуть в работу», плашка «Отменить». Открытая старая версия черновика остаётся на месте.

## 3. «Сегодня» → «Горит на 7 дней»
1. У строки слева круг; нажать: строка уходит, плашка «Выполнено: «название» · Отменить». «Отменить» возвращает строку.
2. У пары с заданиями, которые все выполнены: «1 задание · выполнено».

## 4. Отказы
Задание уже удалено другим путём: «Задание уже удалено» + «Закрыть», список обновился. Задание изменилось: «Задание изменилось, попробуйте ещё раз» + «Повторить». «Отменить» после изменения: объяснение и «Открыть задание».
