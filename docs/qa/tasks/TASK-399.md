# TASK-399: панель агента — очередь, повторная попытка, оборванный ответ

Студент: запускает приложение, открывает панель агента (Ctrl+K) и задаёт вопрос. Сначала видит точки ожидания и таймер.

1. `npm --prefix paratech/desktop/frontend run test` и `run build` — зелёные.
2. Второй вопрос, пока идёт первый: под ним строка «ждёт предыдущий запрос» и два значка. Подсказки: «Остановить предыдущий запрос» (только на самой первой ждущей строке) и «Отменить этот запрос». Таймера у ждущего вопроса нет. Когда первый ответ пришёл, второй уходит сам, строка не остаётся.
3. «Отменить этот запрос» при пустом поле ввода: строка уходит, текст вопроса возвращается в поле, фокус в поле. Если в поле уже набран текст: черновик не тронут, вопрос остаётся тихой строкой «Запрос отменён. Текст можно скопировать.» со значком копирования.
4. Шестой вопрос подряд: строка «Не принят: уже ждут пять запросов. Можно отменить один из них или остановить текущий.»; после отмены одного снова доступно «Отправить ещё раз», вопрос в ленте один раз, без строки «Предыдущий запрос ещё выполняется…».
5. Сбой на стороне Hub: рядом с таймером тихая строка «Повторная попытка N из 3» (N = 1..3, через 5, 10, 20 с); она уходит с ответом или остановкой. Для вопросов по занятиям (`answer_question`) строки пока нет.
6. После трёх неудач напечатанный текст остаётся, под ним «Ответ оборван. Можно повторить.» и один значок «Повторить»; поле ввода доступно, «Нет связи с paratech» не появляется (баннер только при настоящем отсутствии связи). Если запрос остановился из-за потери связи: «Ответ оборван: нет связи. Можно повторить, когда связь вернётся.»
7. Карточка «Не завершено: нет связи.»: значок «Повторить» с одного клика запускает новую попытку (если шаг не открыт, тот же клик продолжает запрос без видимой ошибки).
8. E2E (пакет `paratech/e2e/specs/agent`, через `heavy.sh`): строки «второй вопрос, пока идёт инструмент» и «после оборванного ответа можно писать дальше» — «готово»; D5 («Отменить» обновляет «Предметы») остаётся красной, владелец отложил.
