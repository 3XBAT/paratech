# TASK-351 — один экран пары (проверка владельца)

Начните с холодного запуска приложения. Нужна хотя бы одна пара с записью и конспектом и, лучше, одна пара только с вашими файлами.

1. Откройте «Предметы» → «База знаний» (или кнопку с ней) → предмет → пару. Сразу видны путь «База знаний / <пара>» и вкладки «Мой конспект · Конспект · Текст лекции · Расшифровка · Задания»; кнопки «Открыть конспект» нет. Пока открывается вкладка, видна маленькая строка «Загрузка…».
2. Какая вкладка открылась: «Мой конспект», если в нём есть файлы или текст; иначе «Конспект», если он готов; иначе «Конспект» с состоянием («Готовится…» или ошибка и «Повторить»). Выберите другую вкладку — она не прыгает сама.
3. «Конспект»: одна кнопка «Скопировать» и «⋯» рядом с пунктами «Сохранить как текст (.txt)» / «Сохранить в Markdown (.md)»; абзаца «Конспект хранится на этом компьютере…» и заголовка «Конспект» над текстом нет. Пока конспекта нет, кнопок копирования нет, есть причина и «Повторить».
4. «⋯» в шапке → «Исправить предмет или тип пары»: «⋯» пропадает, фокус в форме. «Закрыть» или «Сохранить» возвращает фокус на «⋯»; после сохранения строка «Предмет и тип пары сохранены.».
5. Alt+← (или кнопка мыши «назад») с любой вкладки возвращает к списку или поиску, где вы были; Alt+→ — снова в пару, на ту же вкладку. Смена вкладок отдельных шагов в истории не создаёт.
6. Поиск по базе → результат внутри конспекта, текста лекции или расшифровки открывает пару на нужной вкладке и показывает найденное место.
7. Пара, открытая из «Предметов» (если есть такой вход): путь «Предметы / <предмет> / <пара>», каждая часть ведёт на свой раздел.
8. Удалите запись в другом окне/месте и откройте её пару: сообщение по-русски и кнопка «Назад», без вкладок.
9. Известное: «Открыть конспект» / «Открыть расшифровку» в строках записей пока открывают старые экраны (TASK-352).
