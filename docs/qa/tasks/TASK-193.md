# TASK-193 — check steps

1. Готовая работа по заданию: в карточке «Отправить преподавателю» -> карточка подтверждения; до «Да» ничего не уходит. После отправки повторная кнопка «Отправить ещё раз» с предупреждением.
2. Работа по теме (без задания): вместо кнопки пояснение, что задания нет.
3. «Сегодня»: ожидающая отправка работы подписана «Работа преподавателю».
4. «Сделать под ключ» до попытки: кнопка «Разобрать задание». Если разбор не удался (например офлайн): причина и «Попробовать снова».
5. «Спросить по шагу»: офлайн, лимит и отказ показывают понятный текст; фраза про отсутствие бэкенда не встречается.
6. Сохранённая неудавшаяся свободная работа: «Обновить»; рядом с неудачной остановкой нет «Повторить».
7. В карточке работы строка «Предмет: … · Тема: …».
8. «Сегодня»: правая колонка шире, «Практические работы 2-4» помещаются в 1–2 строки; с открытой панелью колонка уходит под левую, как раньше.
