# TASK-207 — проверка владельцем: чаты агента

1. Откройте панель агента: в шапке название чата; нажмите на него — список чатов (новые сверху), внизу свёрнутый «Архив».
2. «Новый чат»: появляется пустой чат; повторное нажатие не плодит пустые.
3. «Переименовать»: Enter сохраняет, Esc отменяет; пустое название и длиннее 80 знаков отклоняются.
4. «В архив» / «Вернуть»; откройте архивный чат и отправьте сообщение — чат вернулся из архива.
5. Во время выполняющейся просьбы переключитесь на другой чат: просьба продолжается, её чат помечен в списке; карточки не смешиваются. Переименование/архив во время просьбы — текст «Чат занят…».
6. Смена чата не меняет чип контекста; чип не переключает чат.
7. Прежние просьбы открытого чата показаны текстом (вопрос, строка ответа), упоминания пилюлями, без кнопок.
8. Клавиатура: стрелки/Home/End/Esc/Tab в списке, возврат фокуса; тёмная тема, один акцент. В «Журнале» у строки действия видно название чата.
