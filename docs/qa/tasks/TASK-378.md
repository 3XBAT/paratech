# TASK-378: проверка пакета «Запись → конспект → задание»

Это тест, не функция приложения: студент ничего не увидит. Проверка владельца или супервайзера:

1. Запустите Docker Desktop и дождитесь, пока он будет готов.
2. Закройте свои прогоны E2E (одновременно может идти только один). Своё приложение можно не закрывать: прогон использует свой экземпляр.
3. Выполните (из корня репозитория):
   `bash C:/Users/xvati/GolandProjects/paratech-ops/heavy.sh npm --prefix C:/Users/xvati/GolandProjects/paratech/paratech/e2e run e2e -- --no-build --project=settings --project=recording`
   (первый запуск без `--no-build`: соберёт E2E-приложение).
4. На экране появится окно с пометкой « · E2E»: приложение само импортирует запись, показывает «Расшифровка» → «Конспект готов». Звука нет. Окно закроется само.
5. Откройте `paratech/dist/e2e-run/report/report.md`: все строки «Запись: …» должны быть «готово»; внизу «Скорость расшифровки» (секунды звука / секунды работы, модель, процессор).
6. Проверьте, что ничего не осталось: в диспетчере задач нет `paratech.exe`, `hub.exe`, `whisper-cli.exe` из папки `paratech/dist`.
7. Для полного набора: тот же запуск без `--project` и без фильтров (до 15 минут, сейчас около 2).

Что смотреть в отчёте: если строка «сломано», рядом снимок окна в `report/screenshots`.
Известное: у запущенной расшифровки нет кнопки «Отменить» (отмена проверена через «Удалить» записи): решение владельца в progress/TASK-378.md.
