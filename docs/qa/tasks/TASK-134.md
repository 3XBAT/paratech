# TASK-134 — проверка владельцем

1. Открыть «Предметы» -> «Билеты». Выбрать предмет.
2. Вставить список билетов текстом (или выбрать материал предмета): появляется список и оценка стоимости в долларах.
3. Подтверждение: запуск только по кнопке «Подтвердить и запустить». Если оценка выше лимита ($3, более 33 билетов), кнопка неактивна, пока не отмечена галочка согласия.
4. Во время подбора: статус и «Готово N из M» обновляются сами; при отсутствии интернета, исчерпанных минутах или питании показывается соответствующая пометка.
5. Застрявший набор: пометка «Застряло» и «Запустить снова» (галочки нет).
6. Готовый набор: отчёт о покрытии (покрыто / частично / не покрыто); билеты без ответа (например, запись удалена) — «Не покрыто».
7. «Отмена» и «Вернуть файл во «Входящие»» работают.
8. У готового набора есть кнопка «Открыть .docx»: открывается КОПИЯ файла в Word, подпись «Открыта копия файла»; правки в Word в библиотеку не попадают. Ошибки показываются фиксированным текстом (без путей). Указано, что файл лежит в папке «Билеты» предмета.
9. Названия билетов с `<b>`, ссылками или markdown показываются как обычный текст.
