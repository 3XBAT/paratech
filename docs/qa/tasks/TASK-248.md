# TASK-248 — проверка владельцем: «Скрыть» (ядро, без кнопки в интерфейсе)

Кнопки «Начать заново отсюда» ещё нет (TASK-249), поэтому в приложении это пока не увидеть. Что можно проверить:

1. Холодный запуск: приложение и чаты работают как раньше, кольцо контекста у поля ввода показывает то же, что и до этой задачи. Обычные просьбы не скрывают ничего.
2. Что проверено тестами (go): после перезапуска с «Скрыть» просьбы с выбранной и до последней не попадают ни в контекст агента, ни в список прежних сообщений; ничего не удалено; сделанные действия и журнал остаются; повторный перезапуск работает; сводка контекста сбрасывается, только если она покрывала скрытые просьбы; кольцо после перезапуска опускается; пока просьба идёт или ждёт «Да», перезапуск отказывает («занято»/«нельзя»).
3. Когда появится UI (TASK-249): выбрать прежнее сообщение, «Начать заново отсюда», «Скрыть»; текст сообщения попадает в поле ввода; после отправки все сообщения с него и ниже исчезают из чата, агент их не помнит, действия не отменяются.
