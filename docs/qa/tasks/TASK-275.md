# TASK-275 — «Вернуть» после окна возврата: проверка владельцем

Запуск с нуля: открыть приложение, раздел «Домашние задания». Увидеть список заданий; у строки «Открыть» и «⋯» (в меню «Удалить»).

## 1. Обычное удаление и возврат (не изменилось)
1. «⋯» -> «Удалить» у задания: строка заменяется на «Задание удалено» и кнопку «Вернуть» (в фокусе). Подсказки про 3 дня в строке нет.
2. «Вернуть»: задание на месте, фокус на нём.

## 2. Окно возврата прошло (3 дня)
Нужен запуск с «часами» на 3+ дня позже удаления (или тестовая сборка ядра, где `RestoreAssignment` отвечает `expired`); обычным путём проверить трудно.
1. Удалить задание, не покидая страницы, и дождаться, пока окно закончится (или сдвинуть часы ядра на 73 часа).
2. «Вернуть»: строка превращается в «Задание удалено окончательно, вернуть уже нельзя», кнопки «Вернуть» нет, красной строки отказа нет, список не перечитывается (строка остаётся).
3. Клавиатура: фокус оказался на этой строке (Tab идёт дальше по списку, фокус не пропал); скринридер зачитывает новый текст.
4. То же на странице задания: после «Удалить» -> «Вернуть» строка с текстом меняется так же, кнопка «Все задания» вверху остаётся.
5. Удалить то же задание заново (если оно ещё есть) — строка снова с «Вернуть».

Не делается: подсказка «вернуть можно 3 дня» в строке удаления (нет места, где вернуть после ухода со страницы — решение владельца в progress/TASK-275.md).
