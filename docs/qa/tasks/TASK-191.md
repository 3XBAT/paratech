# TASK-191 — check steps

1. Start a turnkey paper writing. While it runs the card shows «Остановить». Press it: the button turns into «Остановка…», then the card shows «Написание остановлено» and «Продолжить».
2. Press «Продолжить»: writing restarts, the button is «Остановить» again (not «Остановка…»).
3. Double-click «Остановить»: only one stop happens.
4. At the plan step edit the plan and press «Сохранить план» / «Утвердить план». If the work was changed elsewhere meanwhile: «Работа изменилась: обновите карточку.» and the card refreshes.
5. On a ready paper or lab report press «Открыть в Word»: a copy opens in Word; the caption says edits do not return to the app. Double-click opens once.
6. «Открыть в PowerPoint» appears only for a ready presentation (after TASK-106).
