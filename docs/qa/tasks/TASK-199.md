# TASK-199 — check steps

1. Open a finished paper or lab report in the agent panel. The button «Скачать PDF» is there.
2. Click it once: it turns to «Сохранение PDF…» and is disabled; then the line «PDF сохранён в библиотеке рядом с файлом Word.» and «Открыть PDF» appear.
3. The PDF lies in «ДЗ» of the subject next to the .docx. «Открыть PDF» opens a copy (the note under the buttons says so).
4. Regenerate the work («Доработать» or «Написать заново»): «Скачать PDF» is back, the old «Открыть PDF» is gone.
5. A presentation card and a work still being written have no PDF button.
6. On an error the text appears in the card's error line; the button stays.
