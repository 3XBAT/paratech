# TASK-289 — «Удалить предмет» и «Вернуть»: проверка владельцем

Запуск с нуля: открыть приложение, раздел «Предметы». Первым студент видит дерево предметов слева и страницу выбранного предмета; в шапке страницы тихая кнопка «Удалить предмет» рядом с «База знаний», «Билеты», «Добавить файл».

Подготовка: предмет с двумя своими конспектами и одним файлом во вложенной папке (создать папку, затем положить в неё файл).

## 1. Удаление
1. «Удалить предмет»: окно «Удалить предмет «<имя>»? Вместе с ним удалятся 2 моих конспекта и 1 файл. Записи пар и задания останутся. Вернуть можно в течение 3 дней.» Фокус на «Отмена», Tab не выходит из окна, Esc закрывает, фокус возвращается на «Удалить предмет». Пока числа считаются, коротко «Подсчёт моих конспектов и файлов…», «Удалить» недоступна.
2. Сразу после создания папки открыть окно: «Предмет изменился» не появляется (версия читается заново).
3. «Удалить»: открывается другой предмет (или экран плиток), над ним строка «Предмет «<имя>» удалён» с «Вернуть» и «Закрыть». Предмета нет в дереве, его конспектов и файла нет в «Базе знаний» и «Библиотеке».
4. «Вернуть»: предмет снова в дереве и открыт, конспекты и файл на месте.

## 2. Отказы
- Предмет уже удалён другим путём: «Предмет уже удалён» + «Закрыть».
- «Предмет изменился, пока был открыт этот вопрос.» + «Обновить» (вопрос задаётся заново со свежими числами).
- Если прошло больше 3 дней: «Предмет удалён окончательно, вернуть уже нельзя», кнопки «Вернуть» нет.

## 3. Имя удалённого предмета
1. «Добавить предмет» с именем удалённого: «Предмет с таким названием удалён» и «Вернуть»; после «Вернуть» предмет открывается.
2. Расписание: пропущенная строка с таким именем показывает «Предмет с таким названием удалён» и «Вернуть»; после — «Предмет возвращён».

## Что важно знать
- В течение 3 дней записи пар остаются в базе знаний под самим названием предмета (строкой, без предмета в дереве), ADR-0027. Это ожидаемо: записи не принадлежат предмету.
- Строка «Вернуть» после удаления живёт, пока страница открыта; позже вернуть можно, создав предмет с тем же названием (списка «Недавно удалённые» пока нет).
- Окончательное стирание через 3 дня — отдельная задача (TASK-308).
- Только на экране проверяется: фокус в окне и на строках, тёмная тема, озвучивание строк состояния.
